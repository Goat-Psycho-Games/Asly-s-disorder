# Acciones que afectan a la cordura

## Acciones que BAJAN la cordura

| Acción                                  | Efecto en cordura | Notas                         |
| --------------------------------------- | ----------------- | ----------------------------- |
| Presenciar evento traumático            | -10 a -20         | Depende del evento.           |
| Tomar decisión egoísta o violenta       | -5 a -15          | Depende de la decisión.       |
| Fallar ciertos puzzles                  | -5                | Solo puzzles marcados.        |
| Ignorar a ciertos NPCs                  | -5                | Solo NPCs marcados.           |
| Entrar en zonas oscuras o restringidas  | -5                |                               |
| Usar objetos del mundo creepy           | -10               |                               |
| Leer documentos perturbadores           | -5 a -10          |                               |

## Acciones que SUBEN o ESTABILIZAN la cordura

| Acción                                       | Efecto en cordura | Notas                          |
| -------------------------------------------- | ----------------- | ------------------------------ |
| Ayudar a un NPC                              | +5 a +10          |                               |
| Resolver puzzle de forma empática             | +5                |                               |
| Encontrar recuerdo importante                 | +10               |                               |
| Usar objeto de calma                          | +5 a +15          |                               |
| Decisión coherente con personalidad           | +5                |                               |

## Nota importante

No todo debe ser obvio. Algunas acciones que parecen positivas pueden tener un efecto negativo en la cordura a largo plazo.
