# Balanceo del sistema de cordura

## Objetivo

El sistema de cordura debe sentirse orgánico. El jugador no debe poder "optimizar" su cordura trivialmente, pero tampoco debe sentirse castigado injustamente.

## Reglas de balanceo

- El jugador debe poder llegar al final con cualquier rango de cordura.
- Cada rango de cordura debe ofrecer una experiencia diferente pero completa.
- Las penalizaciones de cordura deben ser proporcionales al peso narrativo.
- No todas las partidas deben llegar al mundo creepy.

## Rango objetivo por jugador tipo

| Tipo de jugador         | Rango esperado al final |
| ----------------------- | ----------------------- |
| Explorador completo     | 60-80 (decisiones mixtas) |
| Jugador empático        | 70-100                  |
| Jugador indiferente     | 40-60                   |
| Jugador destructivo     | 0-40                    |

## Puntos de control

En ciertos puntos del juego, la cordura puede tener un "suelo" para no bloquear el progreso.
