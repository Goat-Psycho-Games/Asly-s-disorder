# Puzzles — Visión general

## Filosofía

- Los puzzles son parte de la narrativa, no interrupciones.
- Cada puzzle debe tener sentido en su contexto.
- Los puzzles pueden tener versiones según la cordura y el estado del mundo.
- Nunca deben bloquear el progreso de forma injusta.

## Categorías de puzzles

| Categoría       | Descripción                                              |
| --------------- | -------------------------------------------------------- |
| Exploración     | Encontrar un objeto o información en el entorno.         |
| Combinación     | Combinar objetos para obtener un resultado.              |
| Observación     | Identificar un patrón u elemento en el entorno.          |
| Secuencia       | Activar elementos en el orden correcto.                  |
| Diálogo         | Obtener información de NPCs para resolver algo.          |
| Entorno         | Manipular el entorno para cambiar su estado.             |

## Versiones de puzzle según cordura

- **Versión normal**: solución lógica y observable.
- **Versión distorsionada**: pistas alteradas, solución más difícil de ver.
- **Versión creepy**: solución diferente, simbólica o perturbadora.
