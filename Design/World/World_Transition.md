# Transición entre mundos

## Descripción

La transición entre el mundo normal y el mundo creepy debe sentirse orgánica, no como un cambio de pantalla.

## Tipos de transición

| Tipo           | Descripción                                                |
| -------------- | ---------------------------------------------------------- |
| Gradual        | El entorno se va deteriorando progresivamente.             |
| Por evento     | Un evento narrativo dispara la transición.                 |
| Por cordura    | Llegar a 0-19 de cordura activa el mundo creepy.           |
| Por zona       | Entrar en cierta zona activa el estado creepy local.       |

## Proceso de transición

1. Aparecen los props distorsionados (Distorted_Props).
2. Los cambios de iluminación comienzan.
3. Los NPCs empiezan a comportarse diferente.
4. La versión normal se desactiva gradualmente.
5. La versión creepy se activa completamente.

## Reversibilidad

- Algunas transiciones son temporales (se puede recuperar la cordura).
- Algunas transiciones son permanentes para esa partida.
