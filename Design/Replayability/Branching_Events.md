# Eventos ramificados

## Descripción

Los eventos ramificados son ocurrencias que pueden variar entre partidas según el estado del jugador, sus decisiones y la cordura acumulada.

## Tipos de eventos

| Tipo            | Descripción                                              |
| --------------- | -------------------------------------------------------- |
| Condicional     | Solo ocurre si se cumplen ciertas condiciones.           |
| Probabilístico  | Tiene una probabilidad de ocurrir.                       |
| Exclusivo       | Solo puede ocurrir uno de varios posibles eventos.       |
| Único           | Solo ocurre una vez por partida.                         |
