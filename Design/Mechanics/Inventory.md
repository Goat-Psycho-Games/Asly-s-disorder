# Inventario

## Descripción

El jugador puede recoger y usar objetos a lo largo del juego.

## Características

- Inventario limitado o ilimitado: TBD
- Los objetos tienen descripciones.
- Algunos objetos tienen efecto en la cordura al ser recogidos o usados.
- Algunos objetos solo existen en el mundo normal o en el mundo creepy.
- Algunos objetos cambian de aspecto o descripción según la cordura.

## Tipos de objetos

| Tipo           | Descripción                                      |
| -------------- | ------------------------------------------------ |
| Llave          | Desbloquea zonas o puzzles.                      |
| Documento      | Da información narrativa o pistas.               |
| Objeto de calma| Puede estabilizar la cordura si se usa.          |
| Objeto creepy  | Puede bajar la cordura si se recoge o usa.       |
| Puzzle item    | Necesario para resolver un puzzle específico.    |
