# Sistema de interacción

## Descripción

El jugador puede interactuar con objetos, NPCs y elementos del entorno usando un botón de interacción.

## Funcionamiento básico

1. El jugador se acerca a un objeto interactuable.
2. Aparece un indicador visual (o no, según el estilo elegido).
3. El jugador pulsa el botón de interacción.
4. Se ejecuta la acción definida para ese objeto.

## Tipos de interacción

| Tipo            | Descripción                                     |
| --------------- | ----------------------------------------------- |
| Recoger objeto  | Añade el objeto al inventario.                  |
| Examinar        | Muestra una descripción o texto.                |
| Usar objeto     | Activa una acción del objeto en el entorno.     |
| Hablar          | Inicia un diálogo con un NPC.                   |
| Activar puzzle  | Inicia un puzzle.                               |
| Cambiar estado  | Cambia el estado de un objeto (ej: encender).   |
