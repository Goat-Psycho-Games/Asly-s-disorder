# Datos en JSON

## Descripción

Algunos datos del juego pueden almacenarse como archivos JSON externos para facilitar su edición.

## Casos de uso

- Diálogos extensos.
- Tablas de eventos.
- Configuración de niveles.

## Ubicación de archivos JSON

## Notas

- Los ScriptableObjects son preferibles para datos que se editan frecuentemente en el Inspector.
- Los JSON son útiles para datos que vienen de fuentes externas o que se editan fuera de Unity.
