# Mundo normal vs mundo creepy

## Objetivo visual

El mundo creepy no debe parecer solo una versión roja/oscura del mundo normal. Debe sentirse como una deformación psicológica del mismo lugar.

## Principio de diseño

Cada elemento del mundo creepy debe tener una relación simbólica o narrativa con su versión normal. No es solo "oscuro y roto". Es una manifestación del estado mental del protagonista.

## Cambios por elemento

| Elemento | Mundo normal                    | Mundo creepy                               |
| -------- | ------------------------------- | ------------------------------------------ |
| Paredes  | Limpias, gastadas, con marcas.  | Orgánicas, húmedas, deformadas.            |
| Suelos   | Madera, baldosas, cemento.      | Fluidos, carne, vacío.                     |
| Techos   | Normales, con manchas de humedad.| Inestables, infinitos, rotos.             |
| Luces    | Naturales o fluorescentes.      | Parpadeantes, imposibles, ausentes.        |
| NPCs     | Humanos, presentes.             | Ausentes, deformados o sustituidos.        |
| Objetos  | Funcionales, cotidianos.        | Simbólicos, perturbadores, imposibles.     |
| Puertas  | Abiertas o cerradas normalmente. | Bloqueadas, invertidas, repetidas.        |
| Sonido   | Ambiente realista.              | Ruido, respiraciones, golpes, silencio.   |
| UI       | Limpia, mínima.                 | Leve distorsión, temblores, ausencia.     |
| Color    | Apagado, cálido envejecido.     | Enfermizo, imposible, saturación rota.    |

## Transición visual

La transición entre mundos no debe ser un corte seco. Debe ser progresiva:

1. Pequeños cambios sutiles (Distorted).
2. Cambios medios (sonidos, luces).
3. Transición completa al mundo creepy.
