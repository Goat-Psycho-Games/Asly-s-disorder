# Diseño de entornos

## Principios generales

- Los entornos cuentan la historia sin palabras.
- Cada zona debe tener una personalidad visual propia.
- El mundo normal debe sentirse real pero opresivo.
- El mundo creepy debe sentirse como una pesadilla lógica del normal.

## Plantilla de zona

```md
## [Nombre de la zona]

**Tipo:** Interior / Exterior
**Atmósfera:** TBD

### Mundo normal
- Descripción visual.
- Paleta de color.
- Elementos de escenario clave.
- Iluminación.

### Mundo creepy
- Descripción visual.
- Cambios respecto al mundo normal.
- Elementos nuevos o transformados.
```

## Elementos de entorno recurrentes

- Puertas (abiertas, cerradas, bloqueadas, imposibles).
- Ventanas (transparentes, opacas, rotas, con reflejos extraños).
- Documentos y notas dispersos.
- Objetos que actúan como pistas.
- Fuentes de luz (lámparas, velas, fluorescentes).
