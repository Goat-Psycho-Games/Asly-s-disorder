# Estilo de UI

## Filosofía de la UI

- La UI debe ser casi invisible en estado normal.
- La UI se deteriora o distorsiona según la cordura.
- No mostrar barras de cordura, vida ni stats explícitos.
- El feedback al jugador es visual y sonoro, no numérico.

## Elementos de UI

### HUD (en juego)

- Mínimo o inexistente en estado normal.
- Posible indicador sutil de inventario.
- Distorsión visual cuando la cordura baja.

## Estados de UI según cordura

| Cordura   | Efecto en UI                              |
| --------- | ----------------------------------------- |
| 80-100    | UI limpia y estable.                      |
| 60-79     | Ligero temblor o ruido en los bordes.     |
| 40-59     | Texto levemente distorsionado.            |
| 20-39     | UI parcialmente rota, iconos alterados.   |
| 0-19      | UI casi desaparecida o muy distorsionada. |
