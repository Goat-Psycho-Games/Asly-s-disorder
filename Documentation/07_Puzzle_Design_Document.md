# Puzzle Design Document

## Filosofía de puzzles

- Los puzzles deben integrarse naturalmente en la narrativa.
- Cada puzzle puede tener una versión normal y una versión creepy.
- Versión normal: solución lógica y observacional.
- Versión creepy: solución alternativa, simbólica o perturbadora.
- Ningún puzzle debe bloquear el progreso de forma injusta.

## Tipos de puzzles

| Tipo                | Descripción                                           |
| ------------------- | ----------------------------------------------------- |
| Objetos combinables | Encontrar y combinar objetos para resolver el puzzle. |
| Observación         | Observar el entorno para deducir la solución.         |
| Secuencia           | Activar elementos en el orden correcto.               |
| Diálogo             | Obtener información de NPCs para resolver algo.       |
| Entorno             | Manipular el entorno (estados, objetos, luz).         |
| Cordura             | La solución cambia según el estado mental del jugador.|

## Relación entre puzzles y cordura

- Cordura alta: versión lógica del puzzle.
- Cordura media: pistas sutilmente alteradas.
- Cordura baja: versión alternativa o nueva solución.
- Mundo creepy: puzzle completamente diferente o bloqueado.
