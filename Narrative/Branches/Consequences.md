# Consecuencias

## Tipos de consecuencias

| Tipo          | Descripción                                             |
| ------------- | ------------------------------------------------------- |
| Inmediata     | Ocurre justo después de la decisión.                    |
| Diferida      | Ocurre más adelante en el juego.                        |
| Acumulativa   | El efecto depende de varias decisiones combinadas.      |
| De cordura    | Sube o baja la cordura del protagonista.                |
| Narrativa     | Cambia el estado de un NPC, zona o evento.              |
| De final      | Contribuye a desbloquear o bloquear ciertos finales.    |
