# Asly's Disorder

**Desarrollado por Goat Psycho Games**

Videojuego 2D de scroll lateral desarrollado en Unity, centrado en exploración narrativa, toma de decisiones, puzzles y un sistema oculto de cordura que modifica eventos, personajes, puzzles y el mundo del juego.

## Motor

Unity

## Género

- Aventura narrativa
- Puzzle
- Terror psicológico
- Scroll lateral 2D

## Pilares

1. Decisiones con consecuencias.
2. Sistema de cordura oculto.
3. Mundo normal y mundo creepy.
4. Puzzles adaptativos.
5. Rejugabilidad.

## Estado del proyecto

Preproducción.
